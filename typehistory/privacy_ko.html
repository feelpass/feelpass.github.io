개인정보처리방침

Type History (타입 히스토리) · com.coco.typehistory

핵심 안내: Type History가 기록한 입력 텍스트는 이 기기 안의 로컬 데이터베이스에만 저장됩니다. 서버로 전송되지 않고, 동기화되지 않으며, 개발자를 포함한 누구에게도 공유되지 않습니다. 비밀번호 입력란은 기록하지 않습니다. 다만 이 앱은 Google AdMob 광고를 표시하고 익명 사용 통계·크래시 리포트를 수집하므로, 광고를 불러오고 익명 통계를 보내는 용도로 인터넷 연결과 광고 ID가 사용됩니다. 여러분이 입력한 기록은 그 통신에 포함되지 않습니다.

1. 수집하는 정보

Type History는 계정도, 로그인도, 자체 서버도 없습니다. 앱이 다루는 정보는 다음과 같습니다.

  • 입력한 텍스트 — 기기에만 저장(외부 전송 없음): 접근성 서비스를 통해 다른 앱의 입력란에 입력한 텍스트를 읽어, 앱 이름·시각과 함께 기기 내부의 로컬 데이터베이스(Room)에 저장합니다. 이 데이터는 기기 밖으로 전송되지 않습니다.
  • 비밀번호 입력란 — 기록하지 않음: 비밀번호로 표시된 입력란(isPassword)은 텍스트를 읽기 전에 코드 레벨에서 건너뜁니다.
  • 앱 설정 — 기기에만 저장: 보관 기간, 일시정지 여부, 제외한 앱 목록, PIN 잠금 사용 여부 등의 설정은 앱 전용 저장소에만 보관됩니다. PIN은 원문이 아니라 임의의 솔트를 붙인 SHA-256 해시로만 저장되어 복호화할 수 없습니다.
  • 광고 관련 정보 — Google AdMob이 수집(서버 전송): 광고를 게재하기 위해 AdMob SDK가 광고 ID(AD_ID) 등 기기 식별자와 대략적인 위치, 앱 상호작용 정보를 수집·이용할 수 있습니다. 이는 Google이 수집하는 것이며 개발자에게는 집계된 광고 실적 외에는 제공되지 않습니다. 자세한 내용은 아래 4항을 참고하세요.
  • 익명 사용·진단 정보 — Firebase Analytics·Crashlytics가 수집(서버 전송): 앱 개선과 안정성 확보를 위해 익명 사용 이벤트(예: 기능을 몇 번 썼는지, 어떤 설정을 켰는지 같은 집계 지표)와 비정상 종료 보고서가 전송됩니다. 기록한 텍스트는 물론, 어떤 앱에 입력했는지(패키지명)도 이 이벤트에 포함되지 않습니다. 자세한 내용은 아래 4항을 참고하세요.
  • 수집하지 않는 것: 이름, 이메일, 전화번호, 주소록, 사진, 파일, 정확한 위치, 금융 정보, 건강 정보는 수집하지 않습니다.

2. 접근성 서비스 사용

Type History는 "다른 앱에 입력한 텍스트를 기기에 백업해 두었다가 나중에 복구한다"는 핵심 기능을 위해 Android 접근성 서비스를 사용합니다. Android에서 이 기능을 제공할 수 있는 방법은 이것뿐입니다.

  • 무엇을 읽는가: 텍스트 변경 이벤트(TYPE_VIEW_TEXT_CHANGED) 한 종류만 구독합니다. 이 이벤트로 전달되는 입력란의 텍스트와, 그 텍스트가 입력된 앱의 패키지명을 읽습니다.
  • 어디에 쓰는가: 읽은 텍스트를 이 기기의 로컬 데이터베이스에 저장해, 나중에 앱에서 다시 찾아보고 복사할 수 있게 하는 데에만 사용합니다.
  • 읽지 않는 것: 비밀번호 입력란은 건너뜁니다. 사용자가 제외한 앱과 일시정지 상태에서는 아무것도 기록하지 않습니다.
  • 대신 수행하는 동작 없음: 이 앱은 사용자를 대신해 화면을 클릭·스크롤·이동하거나 양식을 채우지 않습니다. 제스처 수행 권한(canPerformGestures)이나 키 이벤트 필터링을 선언하지 않은 읽기 전용 서비스입니다.
  • 사용자 통제: 접근성 서비스는 기본적으로 꺼져 있습니다. 켜기 전에 앱이 무엇을 읽고 어디에 저장하는지 안내하는 별도의 고지 화면을 표시하고 명시적인 동의를 받습니다. Android 설정에서 언제든 다시 끌 수 있습니다.
  • 이 앱은 감시·모니터링 도구가 아닙니다. 다른 사람의 기기나 메시지에 접근하지 않으며, 다른 사람이 삭제한 메시지를 복구하지도 않습니다.

3. 요청하는 권한

  • 접근성 서비스: 다른 앱의 입력란에 입력한 텍스트를 읽어 기기에 저장(핵심 기능).
  • 인터넷(INTERNET), 네트워크 상태(ACCESS_NETWORK_STATE): 광고를 불러오고 익명 사용 통계·크래시 리포트를 보내는 데에만 사용됩니다. 입력 기록은 이 통신에 포함되지 않으며, 앱의 기록·복구 기능은 인터넷 없이도 완전히 동작합니다.
  • 광고 ID(AD_ID) 및 광고 서비스 권한(ACCESS_ADSERVICES_*): Google AdMob SDK가 광고 게재·측정을 위해 선언하는 권한입니다.
  • 생체 인증(USE_BIOMETRIC): 사용자가 PIN 잠금과 함께 지문·얼굴 인증을 켰을 때 앱 잠금 해제에 사용됩니다. 생체 정보는 Android 시스템이 처리하며 앱은 인증 성공 여부만 전달받습니다.
  • WAKE_LOCK, FOREGROUND_SERVICE: 광고 SDK가 포함하는 Google 라이브러리(WorkManager 등)가 자동으로 선언하는 권한으로, 앱이 직접 사용하지 않습니다.

4. 제3자 서비스

Type History는 다음 제3자 서비스를 사용합니다.

  • Google AdMob: 앱 내 광고(네이티브 광고, 앱 시작 시 전면 광고)를 게재합니다. AdMob은 관련성 있는 광고 제공과 광고 측정을 위해 광고 ID 등 기기 식별자, 대략적인 위치, 앱 상호작용 및 진단 정보를 수집·이용할 수 있으며, 이는 Google에 제공됩니다. 자세한 내용은 Google 개인정보처리방침과 AdMob 안내를 참고하세요.
  • Firebase Analytics: 앱이 어떻게 사용되는지 파악하기 위해 익명 사용 이벤트를 수집합니다. 기록한 텍스트와 대상 앱 패키지명은 이벤트에 포함하지 않으며, 개수·설정값 같은 집계 지표만 전송됩니다. Google 개인정보처리방침을 참고하세요.
  • Firebase Crashlytics: 앱 안정성 개선을 위해 비정상 종료 보고서와 진단 정보를 수집합니다. Google 개인정보처리방침을 참고하세요.
  • 여러분이 입력한 텍스트 기록은 AdMob·Firebase를 포함한 어떤 제3자에게도 전송되지 않습니다.
  • Android 설정 > Google > 광고에서 광고 ID를 재설정하거나 맞춤 광고를 선택 해제할 수 있습니다.

5. 정보의 이용

기기에 저장된 입력 기록은 오직 사용자 본인이 앱에서 다시 찾아보고, 검색하고, 복사·공유·삭제하는 데에만 사용됩니다. 개발자는 이 데이터에 접근할 수 없습니다. 앱의 어떤 정보도 판매하지 않습니다.

6. 데이터 보관 및 삭제

  • 자동 삭제: 설정한 보관 기간이 지난 기록은 자동으로 삭제됩니다. 기본값은 7일이며, 1일 / 3일 / 7일 / 30일 / 90일 / 180일 / 1년 중에서 선택할 수 있습니다.
  • 직접 삭제: 개별 기록을 삭제하거나, 설정의 "모든 기록 삭제"로 전체 기록을 한 번에 지울 수 있습니다.
  • 기록 중지: 설정에서 기록을 일시정지하거나, 특정 앱을 기록 대상에서 제외할 수 있습니다.
  • 앱 삭제: 앱을 제거하면 기록과 설정이 기기에서 함께 삭제됩니다. 서버에 사본이 없으므로 별도의 삭제 요청 절차가 필요하지 않습니다.
  • 앱 잠금: PIN 잠금과 지문·얼굴 인증으로 앱을 잠가, 기기를 잠시 빌려주더라도 기록이 열리지 않게 할 수 있습니다.
