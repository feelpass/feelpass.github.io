1. Getting Started

type expands short text triggers into full text, launches apps, runs actions, and more — all from any text field on your device.

Enable Accessibility Service

  1. Open the type app
  2. Tap the activation toggle
  3. Follow the prompt to enable the Accessibility Service
  4. Grant the necessary permissions

How It Works

Type a trigger keyword anywhere (e.g. in a messaging app, browser, notes), and type instantly replaces it with your configured text or executes an action.

💡 Example: Type //email → automatically replaced with yourname@example.com

2. Text Replacement

Create a Shortcut

  1. Tap the + button
  2. Enter a trigger (the text you type)
  3. Enter the replacement (the text it expands to)
  4. Tap Save

Variables

Insert dynamic content into replacements using variables:

VariableDescriptionExample Output
{date}Current date2025-02-24
{time}Current time14:30
{day}Day of the weekMonday
{clipboard}Clipboard content(pasted text)
{random:a,b,c}Random selectionb

Folders

Organize your shortcuts into folders. Assign colors and icons to keep things tidy.

4. Command Palette

A quick launcher for all your shortcuts — accessible from any screen.

How to Open

  • Volume Down (long press) — default trigger
  • Digital Assistant (power key) — optional
  • Physical keyboard shortcut — configurable

Searching

Start typing to fuzzy-search through your shortcuts. Matching characters are highlighted in green.

Keyboard Navigation

KeyAction
↑ / ↓Navigate between results
Enter / DoneExecute selected shortcut
Esc / BackClose palette

The Command Palette includes a built-in inline calculator. Type a math expression and the result appears instantly above the search results.

💡 Tip: Tap the green result card or press Enter to copy the result to your clipboard.

7. Tips

  • Fuzzy search — The Command Palette uses fuzzy matching. Type chm to find chrome.
  • Shortcut key — Configure a physical keyboard shortcut to open the Command Palette in Settings.
  • Themes — Choose between System, Light, and Dark themes in Settings.
  • Test button — Use the test button in the shortcut editor to preview actions before saving.
  • Trigger prefix — Starting triggers with // helps avoid accidental activations.
