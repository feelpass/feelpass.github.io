1. はじめに

typeは、短いトリガーテキストを入力するだけで、長い文章に展開したり、アプリの起動やシステム操作などのアクションを実行できるアプリです。

ユーザー補助サービスの有効化

  1. typeアプリを開きます
  2. 有効化トグルをタップします
  3. 案内に従ってユーザー補助サービスをオンにします
  4. 必要な権限を許可します

仕組み

メッセンジャー、ブラウザ、メモアプリなど、どこでもトリガーを入力すると、typeが自動的に設定したテキストに置換するか、アクションを実行します。

💡 例：//emailと入力 → 自動的にyourname@example.comに置換

2. テキスト置換

ショートカットの作成

  1. +ボタンをタップ
  2. トリガーを入力（入力するテキスト）
  3. 置換テキストを入力（展開されるテキスト）
  4. 保存をタップ

変数

置換テキストに変数を使って動的なコンテンツを挿入できます：

変数説明出力例
{date}今日の日付2025-02-24
{time}現在時刻14:30
{day}曜日月曜日
{clipboard}クリップボードの内容（貼り付けテキスト）
{random:a,b,c}ランダム選択b

フォルダ

ショートカットをフォルダに分類できます。色やアイコンを設定して整理しましょう。

3. アクション

ショートカットはテキスト置換だけでなく、さまざまなアクションを実行できます：

アクション説明
アプリ起動インストール済みアプリを開く
URL を開くWebアドレスやDeep Linkを開く
電話発信電話番号に直接発信
システム設定特定の設定画面にジャンプ
クリップボードにコピーテキストをクリップボードにコピー
システムツールホーム、戻る、スクリーンショット、ライトなど

4. コマンドパレット

どの画面からでもショートカットを素早く検索・実行できるランチャーです。

開き方

  • デジタルアシスタント（電源キー） — オプション
  • 物理キーボードショートカット — 設定で変更可能
  • ディープリンク — typeaction://palette

ディープリンクで起動

typeaction://palette ディープリンクを使うと、他のアプリや自動化ツールからコマンドパレットを直接起動できます。

連携方法設定
TaskerAction → Send Intent → Data URI: typeaction://palette
MacroDroidActions → Applications → Open Website: typeaction://palette
type パッドアクションタイプ: ディープリンク起動、URL: typeaction://palette
他のランチャーアプリディープリンク/URL実行アクションに typeaction://palette を入力
💡 注意: ディープリンクで起動するにはアクセシビリティサービスが有効である必要があります。サービスがオフの場合、アプリ設定画面に案内されます。

検索

テキストを入力するとファジー検索でショートカットを検索します。マッチした文字は緑色でハイライトされます。

キーボードナビゲーション

キー動作
↑ / ↓結果間を移動
Enter / Done選択したショートカットを実行
Esc / Backパレットを閉じる

5. 電卓

コマンドパレットに内蔵のインライン電卓です。数式を入力すると検索結果の上に緑色の結果カードが表示されます。

💡 ヒント：結果カードをタップするかEnterを押すと、結果がクリップボードにコピーされます。

基本演算

入力結果
2+35
10/33.3333333333
7%31（余り）
2^101024
(2+3)*420

数学関数

関数説明例
sin(x), cos(x), tan(x)三角関数（ラジアン）sin(pi/2) → 1
sqrt(x)平方根sqrt(9) → 3
log(x)常用対数（底10）log(100) → 2
ln(x)自然対数ln(e) → 1
abs(x)絶対値abs(-5) → 5
pow(x,y)べき乗pow(2,3) → 8
ceil, floor, round切り上げ、切り捨て、四捨五入ceil(3.2) → 4

定数と暗黙の乗算

pi（π）とeを直接使用でき、乗算記号なしで続けて書けます：

入力解釈結果
2pi2 × π6.2831...
2(3+4)2 × (3+4)14
2sqrt(9)2 × √96

単位変換

値 単位 to 単位の形式で入力します。

入力結果
100cm to inch39.3700787402 in
1mi to km1.609344 km
1kg to lb2.2046226218 lb
100c to f212 F
1gb to mb1024 MB

対応カテゴリ：長さ、重さ、温度、速度、データサイズ

6. システムコマンド

設定不要ですぐ使える内蔵コマンドです。

システム操作（//command/）

トリガー動作
//command/homeホーム画面へ
//command/back戻る
//command/recent最近のアプリ
//command/noti通知パネルを開く
//command/quickクイック設定
//command/screenshotスクリーンショット
//command/lock画面ロック
//command/flashライト ON/OFF
//command/darkダークモード切替

メディアコントロール（//media/）

トリガー動作
//media/play再生/一時停止
//media/next次の曲
//media/prev前の曲
//media/vol_up音量アップ
//media/vol_down音量ダウン
//media/muteミュート切替

設定ショートカット（//setting/）

トリガー開く設定
//setting/wifiWi-Fi
//setting/btBluetooth
//setting/soundサウンド
//setting/displayディスプレイ
//setting/batteryバッテリー
//setting/dndおやすみモード
//setting/notification通知
//setting/keyboardキーボード/入力
//setting/dev開発者オプション
💡 自動スキャン：typeはデバイスの追加設定画面を自動的に検出・登録します。

アプリ起動（//app/）

インストール済みのすべてのアプリが自動登録されます。コマンドパレットでアプリ名を検索して即座に起動できます。

7. ヒント

  • ファジー検索 — コマンドパレットはファジーマッチングに対応。chmでchromeを検索可能。
  • ショートカットキー — 設定で物理キーボードのショートカットを変更可能。
  • テーマ — システム、ライト、ダークテーマを設定で選択。
  • テストボタン — ショートカット編集画面のテストボタンで保存前にアクションを確認。
  • トリガープレフィックス — //で始めると誤動作を防止。
