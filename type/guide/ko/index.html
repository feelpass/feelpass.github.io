1. 시작하기

type은 짧은 트리거 텍스트를 입력하면 긴 문장으로 확장하거나, 앱 실행·시스템 제어 등 다양한 액션을 수행하는 앱입니다.

접근성 서비스 활성화

  1. type 앱을 열어주세요
  2. 활성화 토글을 탭하세요
  3. 안내에 따라 접근성 서비스를 켜주세요
  4. 필요한 권한을 허용하세요

기본 원리

어디서든 (메신저, 브라우저, 메모장 등) 트리거를 입력하면, type이 자동으로 설정한 텍스트로 교체하거나 액션을 실행합니다.

💡 예시: //email 입력 → 자동으로 yourname@example.com으로 교체

2. 텍스트 교체

단축어 만들기

  1. + 버튼을 탭하세요
  2. 트리거를 입력하세요 (입력할 텍스트)
  3. 교체 텍스트를 입력하세요 (변환될 텍스트)
  4. 저장을 탭하세요

변수

교체 텍스트에 변수를 넣으면 동적인 내용을 삽입할 수 있습니다:

변수설명출력 예시
{date}오늘 날짜2025-02-24
{time}현재 시간14:30
{day}요일월요일
{clipboard}클립보드 내용(붙여넣기 텍스트)
{random:a,b,c}랜덤 선택b

폴더

단축어를 폴더로 분류할 수 있습니다. 색상과 아이콘을 지정해서 깔끔하게 관리하세요.

3. 액션

단축어는 텍스트 교체뿐 아니라 다양한 액션을 실행할 수 있습니다:

액션설명
앱 실행설치된 앱 열기
URL 열기웹 주소 또는 딥링크 열기
전화 걸기전화번호로 바로 연결
시스템 설정특정 설정 화면으로 이동
클립보드 복사텍스트를 클립보드에 복사
시스템 도구홈, 뒤로가기, 스크린샷, 손전등 등
쉘 명령어쉘 명령어 실행 (고급)

4. 커맨드 팰레트

어떤 화면에서든 단축어를 빠르게 검색하고 실행할 수 있는 런처입니다.

여는 방법

  • 볼륨 다운 길게 누르기 — 기본 트리거
  • 디지털 어시스턴트 (전원 키) — 선택 사항
  • 물리 키보드 단축키 — 설정에서 변경 가능

검색

텍스트를 입력하면 퍼지 검색으로 단축어를 찾습니다. 매칭되는 글자는 초록색으로 하이라이트됩니다.

키보드 내비게이션

키동작
↑ / ↓결과 간 이동
Enter / Done선택한 단축어 실행
Esc / Back팰레트 닫기

5. 계산기

커맨드 팰레트에 내장된 인라인 계산기입니다. 수식을 입력하면 검색 결과 위에 초록색 결과 카드가 나타납니다.

💡 팁: 결과 카드를 탭하거나 Enter를 누르면 결과가 클립보드에 복사됩니다.

사칙연산

입력결과
2+35
10/33.3333333333
7%31 (나머지)
2^101024
(2+3)*420

수학 함수

함수설명예시
sin(x), cos(x), tan(x)삼각함수 (라디안)sin(pi/2) → 1
sqrt(x)제곱근sqrt(9) → 3
log(x)상용로그 (밑 10)log(100) → 2
ln(x)자연로그ln(e) → 1
abs(x)절댓값abs(-5) → 5
pow(x,y)거듭제곱pow(2,3) → 8
ceil, floor, round올림, 내림, 반올림ceil(3.2) → 4

상수 & 묵시적 곱셈

pi (π)와 e를 바로 사용할 수 있고, 곱셈 기호 없이 이어 쓸 수 있습니다:

입력해석결과
2pi2 × π6.2831...
2(3+4)2 × (3+4)14
2sqrt(9)2 × √96

단위 변환

값 단위 to 단위 형식으로 입력합니다.

입력결과
100cm to inch39.3700787402 in
1mi to km1.609344 km
1kg to lb2.2046226218 lb
100c to f212 F
100km/h to mph62.1371192237 mph
1gb to mb1024 MB

지원 카테고리: 길이 (mm, cm, m, km, in, ft, yd, mi), 무게 (mg, g, kg, lb, oz, t), 온도 (C, F, K), 속도 (m/s, km/h, mph, knot), 데이터 (B, KB, MB, GB, TB)

💡 한국어 단위도 지원: 100센티미터 to 인치

수식 표시 변환

결과 카드에 표시되는 수식은 자동으로 수학 기호로 변환됩니다:

  • pi → π
  • * → ×
  • sqrt → √
  • 불필요한 괄호 자동 제거

6. 시스템 명령어

별도 설정 없이 바로 사용 가능한 내장 명령어들입니다.

시스템 명령 (//command/)

트리거동작
//command/home홈 화면으로 이동
//command/back뒤로가기
//command/recent최근 앱 목록
//command/noti알림창 열기
//command/quick빠른 설정 패널
//command/screenshot스크린샷
//command/lock화면 잠금
//command/power전원 메뉴
//command/flash손전등 켜기/끄기
//command/dark다크모드 전환

미디어 컨트롤 (//media/)

트리거동작
//media/play재생 / 일시정지
//media/next다음 곡
//media/prev이전 곡
//media/stop정지
//media/vol_up볼륨 올리기
//media/vol_down볼륨 내리기
//media/mute음소거 토글

설정 바로가기 (//setting/)

트리거열리는 설정
//setting/wifi와이파이
//setting/bt블루투스
//setting/sound소리
//setting/display디스플레이
//setting/battery배터리
//setting/storage저장공간
//setting/app앱 관리
//setting/location위치
//setting/dnd방해금지 모드
//setting/notification알림
//setting/keyboard키보드 / 입력
//setting/dev개발자 옵션
💡 자동 스캔: type이 기기에 있는 추가 설정 화면을 자동으로 탐색하여 등록합니다.

앱 실행 (//application/)

설치된 모든 앱이 자동으로 등록됩니다. 커맨드 팰레트에서 앱 이름을 검색하면 바로 실행할 수 있습니다.

7. 팁

  • 퍼지 검색 — 커맨드 팰레트는 퍼지 매칭을 지원합니다. chm을 입력하면 chrome을 찾을 수 있어요.
  • 단축키 설정 — 설정에서 물리 키보드 단축키를 변경할 수 있습니다.
  • 테마 — 시스템, 라이트, 다크 테마를 설정에서 선택하세요.
  • 테스트 버튼 — 단축어 편집 화면에서 테스트 버튼으로 액션을 미리 확인할 수 있습니다.
  • 트리거 접두사 — //로 시작하면 실수로 실행되는 걸 방지할 수 있습니다.
