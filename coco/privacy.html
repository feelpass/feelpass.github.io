Privacy Policy

coco-gmail-reader

1. About This App

coco-gmail-reader is a personal tool. Its developer, feelpass, uses it on a personal Mac. It is not distributed or sold to anyone else.

It is the OAuth client that the open-source command-line tool gog uses to read the developer's own Gmail account. That account is where questions about the developer's apps arrive.

2. Google Data It Accesses

It requests only these scopes:

  • gmail.readonly: Search messages and read their content and attachments. It cannot send, change, or delete email.
  • userinfo.email: See the email address of the signed-in Google account.
  • openid: Sign in with the Google account.

3. How the Data Is Used

Email content is used only by the developer to reply to questions about the developer's apps.

4. Where It Is Processed and Stored

Everything is processed on the developer's own computer. There is no separate server. The sign-in token (refresh token) is stored in the macOS Keychain on that computer.

5. Sharing

Email content is not sold, shared, or transferred to any third party. It is not used for advertising, and it is not used to train AI or machine learning models.

6. Google API Services User Data Policy

coco-gmail-reader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking Access

Access can be revoked at any time at https://myaccount.google.com/permissions.

8. Contact

For questions about this Privacy Policy, contact philleeran@gmail.com.
