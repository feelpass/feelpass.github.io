개인정보처리방침

coco-gmail-reader

1. 이 앱에 대해

coco-gmail-reader는 개발자(feelpass)가 본인 Mac에서 쓰는 개인용 도구입니다. 다른 사람에게 배포하거나 판매하지 않습니다.

오픈소스 명령줄 도구 gog가 이 OAuth 클라이언트로 개발자 본인의 Gmail 계정을 읽습니다. 이 계정은 개발자가 만든 앱의 문의 메일을 받는 곳입니다.

2. 접근하는 Google 데이터

개발자 본인 소유의 Gmail 계정 6개에 씁니다. 개발자 개인 계정과 앱 운영용 계정입니다.

다음 권한을 요청합니다.

  • gmail.readonly (계정 5개): 메일을 검색하고 본문과 첨부를 읽습니다. 메일을 보내거나 수정하거나 삭제할 수 없습니다.
  • gmail.modify (광고 문의 계정 1개만): 메일을 읽고, 임시보관함에 답장 초안을 만들고 고칩니다. 이 권한으로 메일을 보낼 수도 있지만, 이 도구는 메일을 보내거나 삭제하지 않습니다. 답장은 개발자가 Gmail에서 직접 보냅니다.
  • gmail.settings.basic, gmail.settings.sharing (광고 문의 계정 1개만): 이 계정이 어떤 주소로 보낼 수 있는지(보내는 주소 별칭) 확인합니다. 설정은 바꾸지 않습니다.
  • userinfo.email (모든 계정): 로그인한 Google 계정의 이메일 주소를 확인합니다.
  • openid (모든 계정): Google 계정으로 로그인합니다.

3. 이용 목적

메일 내용은 개발자가 앱 문의와 광고 문의에 답하는 데만 씁니다. 광고 문의 계정에서는 답장 초안을 만드는 데도 씁니다.

4. 처리와 저장 위치

모든 처리는 개발자 본인 컴퓨터에서 이루어집니다. 별도 서버는 없습니다. 로그인 토큰(refresh token)은 이 컴퓨터의 macOS 키체인에 저장합니다.

5. 제3자 제공

메일 내용을 판매하거나 제3자에게 공유·전송하지 않습니다. 광고에 쓰지 않고, AI·머신러닝 모델 학습에도 쓰지 않습니다.

6. Google API 서비스 사용자 데이터 정책

coco-gmail-reader가 Google API에서 받은 정보를 사용하고 전송하는 방식은 제한적 사용(Limited Use) 요건을 포함해 Google API 서비스 사용자 데이터 정책을 준수합니다.

7. 접근 권한 철회

https://myaccount.google.com/permissions에서 언제든 접근 권한을 철회할 수 있습니다.
