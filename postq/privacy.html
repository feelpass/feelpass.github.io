Privacy Policy

postq · postq.plantcode.app

In short: postq is a personal tool that runs only on the developer's own computer and connects only to the developer's own social media accounts. It has no server of its own. Account tokens and post data are stored on that computer and are not sold or shared with anyone.

1. Who uses postq

postq is used only by its developer to manage the developer's own Instagram, Threads and YouTube accounts. It is not offered to other users. If someone else ever signs in to postq with their own account, this policy applies to them in the same way.

2. Information postq accesses

  • YouTube (YouTube API Services): the connected channel's ID and name, the videos that postq uploads, and the statistics and comments for those videos. postq uploads videos, reads their status, statistics and comments, posts replies to comments, and deletes videos that postq uploaded when the user asks it to.
  • Instagram and Threads (Meta APIs): the connected account's ID and username, the posts that postq publishes, and the insights and comments for those posts. postq publishes posts, reads insights and comments, and posts replies.
  • Access tokens: the OAuth access and refresh tokens that each platform issues when the user connects an account.
  • Content to publish: captions, titles and media files that the user prepares for scheduling.

3. How the information is used

The information is used only to publish the user's scheduled posts, to show the user the status, statistics and comments of those posts, and to send replies that the user approves. It is not used for advertising, it is not sold, and it is not used to build profiles of anyone.

4. Where it is stored

Access tokens, post records, statistics and comments are stored in a local database file on the developer's computer, readable only by that computer's user account. Media files to be posted on Instagram and Threads are uploaded to a public storage bucket (Supabase Storage), because those platforms fetch media from a public URL; those files contain only content that is about to be published publicly anyway.

5. Sharing

postq does not share user data with third parties. Data is sent only to the platform it belongs to (for example, a video is sent to YouTube when it is uploaded), and media files are stored in the storage bucket described above.

6. YouTube API Services

postq uses YouTube API Services. By connecting a YouTube account to postq, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

postq's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

Records are kept until the user deletes them from postq. When a post is deleted from postq, its statistics and comment copies are deleted with it. Statistics and comments obtained from the platforms are refreshed or deleted at least every 30 days. Deleting the local database removes all stored data and tokens.

You can revoke postq's access at any time:

  • Google / YouTube: Google account security settings
  • Instagram: Instagram app → Settings → Website permissions → Apps and websites
  • Threads: Threads app → Settings → Account → Website permissions

When access is revoked, postq can no longer read or post anything for that account.

8. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
